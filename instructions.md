- Implement all the needed code to finish the sprint 
- Hire a cybersecurity engineer to perform audit and create an audit report with findings under implementation/audits
- Hire a QA Dev to create test units and create a test report under implementation/testing
- Address and fix all issues in the audits and testing and create a document under implementation/results
